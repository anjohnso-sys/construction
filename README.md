## Adding a project

1. Create a new folder named after the project, lowercase with hyphens (for example `pattern-project/`).
2. Put the guide inside it as `index.html`.
3. Add a link to it in the root `index.html` by copying an existing `<li>` line.
4. Add a row to the table above.
